Build a **complete, fully functional, production-quality demo website/web application** for a premium photography studio named **“Radiant Photography”**.

This is NOT just a visual mockup and NOT just a single landing page.

Create the complete multi-page website with working navigation, interactions, filtering, lightbox, booking form, responsive layouts, animations, mobile navigation and all necessary UI states.

The website will initially be used as a **high-quality demo for a real photography studio client**, so it should look polished enough to present directly to a client. The content, images, contact information and branding should be easy to replace later.

# ANIMATION ARCHITECTURE

Use the two animation libraries intentionally.

## GSAP

Use **GSAP + ScrollTrigger** for cinematic, page-level and scroll-driven animations.

Official reference:
https://gsap.com/

Use GSAP for:

* Hero image reveal
* Hero typography entrance
* Image clip/reveal animations
* Scroll-triggered section reveals
* Parallax photography
* Large image scale transitions
* Pinned storytelling sections
* Portfolio image choreography
* Editorial text reveals
* Section transitions
* Cinematic page entrance sequences

GSAP animations should feel slow, elegant and cinematic.

Do NOT animate every element.

---

## Motion

Use **Motion for React** for interactive UI elements.

Official reference:
https://motion.dev/

Use Motion for:

* Mobile navigation
* Menu open/close
* Buttons
* Hover interactions
* Portfolio filtering transitions
* Lightbox open/close
* Image transitions
* Modal animations
* Form interactions
* Accordion interactions
* Page/component transitions
* Subtle micro-interactions
* Layout transitions
* Active navigation states

Do not use GSAP and Motion for the exact same animation unnecessarily.

GSAP = cinematic storytelling / scroll animation.

Motion = UI interaction / component animation.
